# phumintr888

เว็บไซต์: https://thunwa-leo.github.io/phumintr888/  
โค้ด: https://github.com/Thunwa-LEO/phumintr888

เว็บแพลนเนอร์สำหรับนักเรียน: ตารางเรียน การบ้าน และการแจ้งเตือนก่อนถึงกำหนดส่ง

## ฟีเจอร์

- ตารางเรียน 5–7 วัน และ 5–10 คาบ
- คลิกช่องตารางเพื่อเพิ่ม/แก้ไขรหัสวิชาและห้องเรียน
- เพิ่ม/แก้ไข/ลบการบ้าน พร้อมค้นหาและกรอง
- แจ้งเตือนงานใกล้ถึงกำหนดในหน้าเว็บ และ Browser Notification (ถ้าอนุญาต)
- นำเข้ารูปตารางเรียนด้วย OCR
  - อ่านเฉพาะรหัสวิชาและห้อง
  - รองรับวันอยู่ด้านบนหรือด้านซ้าย
  - ตรวจแก้ผลลัพธ์ก่อนบันทึก
- ส่งออก/นำเข้าข้อมูลสำรองเป็น JSON
- เก็บข้อมูลในเบราว์เซอร์ด้วย `localStorage`
- รองรับหน้าจอคอมพิวเตอร์ แท็บเล็ต และมือถือ

## เปิดใช้งาน

ไฟล์เว็บทั้งหมดอยู่ใน `index.html`

```bash
python3 -m http.server 8899
```

แล้วเปิด `http://127.0.0.1:8899/index.html`

> แนะนำให้เปิดผ่าน HTTP/localhost เพราะ qutebrowser และเบราว์เซอร์บางตัว
> ไม่อนุญาตให้หน้า `file://` โหลดไลบรารี OCR จากอินเทอร์เน็ต

## ข้อมูลและการสำรอง

- ข้อมูลถูกเก็บใน `localStorage` ใต้คีย์ `phumintr888-planner-v1`
- เวอร์ชันเดิมที่ใช้ชื่อ `pumin888` จะถูกย้ายข้อมูลให้อัตโนมัติเมื่อเปิดใน origin เดิม
- ข้อมูลจะคงอยู่หลังรีเฟรช/ปิดเปิดเบราว์เซอร์ แต่จะหายหากล้าง Site Data
  หรือเปลี่ยนเบราว์เซอร์/อุปกรณ์
- ใช้เมนู **เริ่มต้นใหม่ / จัดการข้อมูล → ส่งออก** เพื่อสำรอง และ **นำเข้า** เพื่อกู้คืน
- เว็บนี้เป็น static site จึงยังไม่มีบัญชีผู้ใช้หรือการซิงก์ข้อมูลข้ามอุปกรณ์

## OCR

ใช้ Tesseract.js (ไทย + อังกฤษ) โดยประมวลผลรูปในเบราว์เซอร์
ไม่มีการอัปโหลดรูปขึ้นเซิร์ฟเวอร์ และต้องต่ออินเทอร์เน็ตครั้งแรกเพื่อโหลดไลบรารี
